## 三视角怎么用

- **成熟度**：入门（1）→ 熟练（2）→ 精通（3），该能力在 FDE 成长路径上的通常位置。新入行者按成熟度由低到高读。
- **阶段**：能力主要发挥在客户旅程的哪一段——全程基石 / 售前获客 / 部署激活 / 续约留存 / 扩展增收 / 规模化。
- **AI 杠杆**：该能力被 AI 放大的程度。高杠杆项是「FDE + AI」复合竞争力的优先投资方向。
